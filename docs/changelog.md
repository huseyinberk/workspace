## Versioning

This project uses semantic versioning: `vMAJOR.MINOR.PATCH`.

- Increment **MAJOR** for changes that substantially alter the site's structure or experience.
- Increment **MINOR** when adding a meaningful new capability or collection of notes.
- Increment **PATCH** for small fixes, copy edits, and visual refinements.
